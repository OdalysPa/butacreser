CinemaBookingSystem

Proyecto de sistema de reservación de butacas de cine desarrollado con **.NET 8 (Backend)** y **React (Frontend)**, utilizando **SQL Server** como base de datos.

 Descripción

Este sistema permite a los usuarios registrar clientes, seleccionar películas en cartelera, reservar butacas y visualizar el historial de reservas. Además, los administradores pueden gestionar salas, asientos, películas y funciones (carteleras).

Desarrollado por **Odalys Pincay**, programador junior apasionado por la creación de soluciones tecnológicas funcionales y bien estructuradas.


Tecnologías utilizadas

Backend (.NET 8 - C#)
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- LINQ
- Arquitectura en capas

 Frontend (React)
- React + TypeScript
- Context API para manejo de estado
- Axios para consumo de la API
